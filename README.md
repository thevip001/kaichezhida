# 开车直达

开车直达是一个浏览器用户脚本：以车身造型作为快捷导航面板，包含 5 个车库和 3×3 快捷入口。

## 安装

1. 安装 Tampermonkey 或兼容的用户脚本管理器。
2. 打开本仓库的 开车直达.user.js。
3. 点击 Raw，复制脚本内容，在 Tampermonkey 中新建脚本并粘贴保存；或通过 Greasy Fork 同步本仓库。

## 使用

- 快捷键：Shift + Q 打开或关闭面板。
- 顶部：5 个车库，可切换并管理快捷入口。
- 底部：3×3 快捷入口，可添加、拖动、重命名和删除。
- 设置：更换背景、调整按键透明度、修改快捷键、导入导出配置。

## 图片素材

图片/ 目录保存车身原图与三色图素材。当前已有 5 款车的基础图，第一款另含三色图；其余三色图后续补充。
