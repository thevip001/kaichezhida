# 开车直达

**一键收藏网页，可以设置密码，进行私密收藏。**

车位就是网站，车库就是收藏夹，车牌号就是密码。把常用网页停进车库，需要时一键打开。

一键拨号，叫车直达。

## 把网页“停”进车库

遇到想保存的网页，不用复制链接，也不用手动填写网址：

1. 打开“开车直达”，选择一个车库。
2. 点击“停车入位”，一键收藏当前网页。
3. 下次打开车库，点击对应车位，即可在新标签页访问。

网页标题和网站图标会自动读取，收藏后也可以自行修改名称，让入口更好认。

## 车位就是网站，车库就是收藏夹

用熟悉的停车方式，管理自己的网页收藏：

- 车位：每个车位存放一个网站，点击即可直达。
- 车库：每个车库是一组收藏，可以按工作、学习、工具、阅读等用途分类。
- 停车入位：把当前网页保存到选中的车库。
- 车牌号：给指定车库设置密码，解锁后再查看里面的收藏。

内置五个车库，每个车库九个车位，共可存放四十五个网站。同一车库内不会重复收藏完全相同的网址。

## 常用收藏随手开，私密收藏上把锁

普通网站随手收藏，希望减少他人随意查看的内容，可以放进设置了车牌号的车库。

在“设置”中选择车库，输入车牌号并保存，即可为它上锁。访问时输入正确密码，才能查看和操作里面的网站；切换离开该车库或关闭面板后，会重新锁定。

不同车库可以分别设置密码，也可以保留为不加锁的普通收藏夹。

> 车牌号提供的是界面访问限制，不是对收藏数据进行加密。配置备份中仍包含收藏网址，请妥善保管，不要把它当作保存账号密码或敏感信息的保险箱。

## 拖一拖，整理自己的收藏

不用反复删除再添加，直接拖动就能调整：

| 操作 | 效果 |
|---|---|
| 拖到空车位 | 将网站移到指定位置 |
| 拖到已有网站的车位 | 两个网站交换位置 |
| 拖到上方其他车库入口 | 将网站移入另一个车库 |
| 双击车库 | 修改收藏夹名称 |
| 双击已有网站的车位 | 修改网站名称，或删除收藏 |

删除后原车位留空，其他网站不会自动挤动，方便保留自己习惯的排列。跨车库移动时，目标车库需要有空位；上锁的车库需要先解锁。

## 随时呼出，用完收起

默认按 `Alt＋A` 打开或关闭面板，也可以在脚本管理器菜单中打开。

- 拖动标题区域，调整面板位置。
- 点击图钉，让面板在打开网站后保持显示，方便连续访问。
- 未置顶时，点击网站后面板自动收起。
- 支持小、中、大三档尺寸。
- 支持更换内舱背景、调整按钮透明度和自定义快捷键。

当前版本使用原默认黑色车型，不提供其他车型或颜色切换。车身素材已内嵌，功能区是可点击、可拖动的真实操作界面。

## 收藏备份，换浏览器也能带走

在设置中导出配置，即可保存车库、网站收藏及相关设置。更换浏览器或重装脚本后，可以导入备份恢复。

导入会覆盖当前配置，不会自动合并两份收藏；导入前建议先备份。当前没有内置自动云同步，迁移通过配置文件完成。

## 安装与开始使用

1. 安装 Tampermonkey 等用户脚本管理器。
2. 导入“开车直达”脚本并启用。
3. 刷新普通网页，按 `Alt＋A` 呼出面板。
4. 选择车库，点击“停车入位”，开始收藏。

更新时直接更新原脚本，避免同时启用多个版本。

## 使用小提示

- 空车位表示还有位置，新增当前网页请点击“停车入位”。
- 一个车库最多九个网站，满位后可换车库，或整理已有收藏。
- 如果快捷键与其他操作冲突，可以在设置中修改。
- 在输入框中打字时，全局呼出快捷键不会触发。
- “一键拨号，叫车直达”是快捷访问的趣味表达，实际功能是打开收藏网页，不涉及电话拨号或网约车服务。

把网页停好，把常用留在手边，把私密收藏锁进自己的车库。
