# 车身图片素材

请将车身原图或多车型拼图上传到本目录。无需在聊天中重复上传。

## 上传方式

在 GitHub 打开本目录，选择 Add file → Upload files，选择图片并提交到 main 分支。上传完成后，在对话中告知文件名或发送仓库文件链接。

## 图片要求

- 优先原始 PNG、JPG 或 WebP 文件，不要截图压缩。
- 单车型图片、多车型拼图均可，无需自行裁切。
- 车头朝上为优先；如原图方向不同，请保留原图，后续统一处理。
- 请勿上传密码、令牌或其他隐私信息。本仓库为公开仓库。
